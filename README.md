# simfull-app

Full building, thermal network, and multi-domain simulation software.

## Features
- **Network Model (Level 1)**: Multi-zone thermal network, building envelope, emitters, heat pump plant, piping, time-series stepping with weather.
- **Local Spatial Fields (Level 2)**: 1D multi-layer finite difference wall conduction and 2D finite difference thermal bridge solver (EN ISO 10211).
- **Multi-Domain Expansion**: Unified network architecture supporting thermal, fluid, electrical (PV/battery), and structural domains.
- **Geometry & CAD**: Interactive 2D floorplan canvas editor, standard geometry schema, and 3D STL mesh import.
- **Interactive Web Application**: 3D spatial colored mesh results visualization and time-series dashboards.
